# Chinese Answers Over English Papers

Preferred style:

```md
这篇论文的核心贡献是...

具体来说：
- ...
- ...

局限或注意点：
- ...

---
**Sources:**
- paper_name.pdf
```

Terminology:
- Keep model, metric, dataset, and loss names in English.
- Translate high-level explanation into Chinese.
- If a term has a standard Chinese translation, use `中文（English）` on first mention.
